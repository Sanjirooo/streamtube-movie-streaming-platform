# StreamTube - Movie Streaming Platform

# Overview

StreamTube is a web-based movie streaming platform developed as a final project for the Software Development course.

This project was created to implement web application development concepts, including frontend and backend integration, database management, user authentication, and membership-based features.

StreamTube allows users to browse movie collections, search for available movies, view movie details, manage personal accounts, track watch history, and access membership features through an integrated web application system.


# Features

The application includes several main features:

- User registration and login system
- User authentication and session management
- Movie catalog browsing
- Movie search functionality
- Movie category filtering
- Movie detail page
- Watch history tracking
- Personal movie list management
- User profile management
- Membership system
- Admin dashboard for managing application data


# Technology Used

This project was developed using:

- PHP as the backend programming language
- MySQL as the database management system
- HTML, CSS, and JavaScript for the user interface
- XAMPP as the local development environment

# Project Structure

The project is organized into several main directories:

- `admin/` contains administrative features and management pages
- `api/` contains backend API-related functions
- `assets/` contains frontend resources such as stylesheets, scripts, and images
- `config/` contains application configuration files
- `database/` contains database structure and SQL files

The main application pages include:

- `index.php` as the homepage
- `login.php` for user authentication
- `register.php` for account registration
- `detail.php` for movie information
- `search.php` for movie searching
- Other supporting pages for user features

The application uses MySQL to store and manage application data, including user accounts, movie information, membership data, and user activity such as watch history.
